# Снимок реального выпуска

Место для `telegram-digest.png`, полученного в личном чате владельца после запуска с действующими токенами. Для защиты на снимке должны быть видны дата выпуска, блок автора, количество новых постов, ссылки и итог. Перед публикацией обрежьте лишние сведения о личном чате.

Сценарий получения такого выпуска описан в [инструкции для преподавателя](../../README.md#проверка-преподавателем).
